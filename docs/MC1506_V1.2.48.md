# Expediente anual
Consultar año, seleccionar técnica, consultar aprobación, revisar cobertura y confirmar. Se conserva una instantánea inmutable por analista/año/técnica. Si cambia el alcance o la evidencia, se señala como histórica. No se implementa reaprobación, firma FEI ni archivo de plantilla en esta entrega. La validación de cobertura se ejecuta en cliente; las reglas restringen creación a gestores y protegen la instantánea, pero no verifican cada resultado ni eliminan la ventana de concurrencia entre consulta y transacción. Desplegar reglas antes de usar. Validar en entorno de pruebas antes de producción.
