# Estándar FEI-PSI
Usar feiReceipt(registro, fuente, constanciaAlternativa) en documentos HTML; para PDF vectorial usar feiData. No añadir otra constancia de la misma firma. Mantener una constancia por firmante y conservar el texto alternativo para registros sin PIN. No alterar registros ni PDF archivados. El QR verifica el registro, no el archivo PDF.
