PSI SGC NEXTGEN V1.1.01 — PWA instalable

Subir contenido de ZIP a raíz de GitHub. Netlify: npm run build, dist. En Chrome abrir URL HTTPS y usar botón Instalar aplicación (si navegador lo permite) o menú ⋮ > Guardar y compartir > Instalar página como aplicación. En macOS también puede usar el menú de Chrome. No se activa caché offline de registros confidenciales.

Conservar variables privadas FIREBASE_SERVICE_ACCOUNT_JSON solo en Netlify, nunca en GitHub. Publicar reglas Firestore manualmente si corresponde.
